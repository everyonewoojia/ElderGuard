# 银发守护 - 空巢老人智能看护系统

## 项目简介

银发守护是面向空巢、独居老人的智能看护辅助工具，构建**感知→理解→规划→执行→反馈→记忆**完整服务闭环。

**系统定位**：辅助看护工具，不替代医疗诊断，不提供医疗救治。

## 技术栈

| 组件 | 技术选型 | 说明 |
|------|---------|------|
| 老人端 | Python + Vosk | 离线语音识别 |
| 云端 ASR | 阿里云实时语音识别 | 云端语音转文字 |
| 云端 TTS | 阿里云智能语音合成 | 文字转语音 |
| 大模型 | 通义千问 qwen-turbo | 意图理解、对话生成 |
| 短信推送 | 阿里云短信服务 | 告警通知家属 |
| 云端框架 | FastAPI | REST/WebSocket |
| 数据库 | SQLite | 轻量部署 |
| 家属端 | 微信小程序 | 无需独立安装 |

## 快速开始

### 1. 环境准备

```bash
# Python 3.8+
# Node.js 14+（小程序开发）
# 微信开发者工具
```

### 2. 配置环境变量

```bash
# 云端
cd cloud-server
cp .env.example .env
# 编辑 .env 填入 API Key

# 老人端
cd elder-agent
cp .env.example .env
# 编辑 .env 填入配置
```

### 3. 安装依赖

```bash
# 云端
cd cloud-server
pip install -r requirements.txt

# 老人端
cd elder-agent
pip install -r requirements.txt
```

### 4. 启动服务

```bash
# 云端
cd cloud-server
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# 老人端
cd elder-agent
python src/main.py

# 小程序
# 使用微信开发者工具打开 family-miniapp 目录
```

## API 接口

| 接口 | 方法 | 说明 | 鉴权 |
|------|------|------|------|
| /api/v1/auth/login | POST | 家属登录 | 否 |
| /api/v1/elder/{id} | GET | 查询老人信息 | 是 |
| /api/v1/elder/{id}/logs | GET | 查询监护日志 | 是 |
| /api/v1/tasks | POST/GET | 创建/查询提醒任务 | 是 |
| /api/v1/alerts/{id} | GET | 查询告警记录 | 是 |
| /api/v1/alerts/{id}/cancel | POST | 取消误告警 | 是 |
| /api/v1/privacy/auth | POST | 修改隐私授权 | 是 |
