# 银发守护 — 答辩演示脚本（P0 核心闭环）

> 配套材料：`docs/答辩交付材料.docx`（项目完整说明）、`README.md`（质量验收与模拟边界）。
> 演示建议时长 8–10 分钟。依赖本机已装的 Python 3.12（`D:\Environment\Python312`）与微信开发者工具。

## 演示总览（一句话主线）

**“老人端感知→云端中枢→家属端联动”的空巢老人看护闭环**，从主动语音求助到家属收到告警、再到隐私授权全程可控。

---

## 第一部分：系统启动（1 分钟）

1. **云端启动**
   ```
   cd cloud-server
   D:\Environment\Python312\python.exe -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
   ```
   访问 `http://127.0.0.1:8000/docs` 展示自动生成的 OpenAPI 文档。

2. **老人端启动**
   ```
   cd elder-agent
   D:\Environment\Python312\python.exe src/main.py
   ```
   展示事件总线、调度器、记忆、插件初始化日志。

## 第二部分：核心业务闭环（4 分钟）

### 场景 A：家属登录与老人绑定（FR-FL-01）
- 微信开发者工具打开 `family-miniapp`，进入登录页。
- 输入家属账号密码登录（OAuth2 表单）。
- 登录后首页 `GET /api/v1/elder` 展示**仅本人绑定**的老人（越权 0 次，AQ01）。

### 场景 B：老人主动语音求助 → 家属告警（FR-SC-01/FR-SC-05，KK01）
- 老人端模拟输入“救命 / 我不舒服”。
- 老人端：本地语音告警兜底 + 高危 P0 事件入总线。
- 云端：`POST /api/v1/edge/alerts` 写入 AlertLog，触发 WS 推送家属端。
- 家属小程序告警记录页收到该告警（**≤10 秒送达**）；`GET /api/v1/alerts` 可查历史。

### 场景 C：提醒任务同步下发（FR-FL-06）
- 家属在设置页新增用药提醒 `POST /api/v1/tasks`。
- 老人端 `GET /api/v1/edge/tasks` 拉到激活任务并按时提醒。

### 场景 D：隐私授权联动（FR-CM-05 / AQ02）
- 家属关闭隐私授权 `POST /api/v1/privacy/auth`。
- 老人端 `GET /api/v1/edge/privacy` 拉取后本地 PrivacyGuard 关闭 → **未授权采集 0 次**。

## 第三部分：质量与硬约束验收（2 分钟）

本机终端运行三端全量测试，展示结果：

```
# 云端
cd cloud-server && D:\Environment\Python312\python.exe -m pytest -q          # 98 passed
# 老人端
cd elder-agent && D:\Environment\Python312\python.exe -m pytest -q           # 88 passed
# 小程序
cd family-miniapp && node --test tests/api.test.js tests/pages.test.js       # 12 passed
```

讲解三类硬约束均已落地：
- **AQ01 越权访问 0 次**：行级隔离 + 鉴权依赖（`get_bound_elder` → 403）。
- **AQ02 / CON-B-04 未授权采集 0 次**：PrivacyGuard 双校验。
- **CON-B-01 / CON-L-06 无医疗诊疗建议**：话术仅“通知家属/保持冷静”，绝无诊疗结论。

## 第四部分：P1/P2 能力与模拟边界（1–2 分钟）

- **P1**：WebSocket 实时推送、告警重试（≤3 次）、主动陪伴、视觉行为识别（10 秒无应答告警）、误告警取消不重推、日志清理、跌倒通话。
- **P2 接口预留**：毫米波雷达/穿戴设备、社区后台对接、情绪识别、多模态融合、批量存储。
- 明确模拟边界：AI 走外部 API + 本地兜底、视觉/通话为模拟、断网缓存为内存级、小程序为 mock 逻辑测试。

## 结束语（30 秒）

银发守护以「辅助看护、不替代医疗」为定位，前后端分离 + TDD 分阶段交付，P0 全量回归通过，硬约束全部满足，核心闭环可演示。
