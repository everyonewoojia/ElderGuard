# 银发守护 · 接口契约（v1.0）

> 本文档依据《空巢老人智能看护（银发守护）架构设计文档》第 9 章固化，供三端（老人端、云端、家属端）对齐联调用。所有实现与测试均以此契约为准；修改需同步更新本文档及对应契约校验测试。

## 1. 通用约定

- 基础路径：`/api/v1`
- 认证方式：JWT Token（请求头 `Authorization: Bearer <token>`）
- 统一错误码：`400` 参数错误、`401` 未鉴权、`403` 越权、`404` 不存在、`500` 服务异常
- 统一响应格式：

```json
{ "code": 200, "message": "success", "data": {} }
```

## 2. REST 接口

| 接口 | 方法 | 说明 | 鉴权 | 优先级 |
| --- | --- | --- | --- | --- |
| `/auth/login` | POST | 家属登录鉴权 | 否 | P0 |
| `/elder/{id}/logs` | GET | 查询老人监护日志 | 是 | P0 |
| `/tasks` | POST / GET | 创建、查询提醒任务 | 是 | P0 |
| `/tasks/{id}` | DELETE | 删除提醒任务 | 是 | P0 |
| `/alerts` | GET | 查询历史告警记录 | 是 | P0 |
| `/alerts/{id}/cancel` | POST | 取消误告警 | 是 | P1 |
| `/privacy/auth` | POST | 修改隐私授权开关状态 | 是 | P0 |
| `/health` | GET | 健康检查（非业务） | 否 | — |

所有家属接口必须携带鉴权令牌；服务端校验家属与老人的绑定关系，越权访问返回 `403`。

## 3. WebSocket 接口

- `/ws/alerts`：向家属小程序实时推送告警事件。连接时携带鉴权令牌，服务端校验绑定关系；断线后支持重连，重连后补推未确认告警（P1 落地）。

## 4. 统一事件 JSON 格式

```json
{
  "eventId": "string",
  "type": "fall|sedentary|voice|config|alert",
  "priority": "P0|P1|P2",
  "timestamp": "ISO8601",
  "source": "edge|cloud|family",
  "payload": {},
  "authToken": "string"
}
```

- `type` 取值：`fall` 跌倒、`sedentary` 久坐、`voice` 语音、`config` 配置变更、`alert` 告警。
- `priority` 用于事件总线优先级调度：P0 > P1 > P2。
- `authToken` 用于内部事件鉴权，外部请求不使用该字段。

## 5. 插件统一接口

所有业务插件实现统一接口，内核通过事件总线分发事件，插件异常不影响内核与其他插件：

- `init()`：插件初始化
- `start()`：启动插件
- `stop()`：停止插件
- `handle_event(event)`：处理输入事件

## 6. AI 门面统一接口

AI 能力支撑层对外统一封装，屏蔽第三方差异；外部 API 失败时返回明确错误码，由上层执行兜底策略：

- `asr(audio)`：语音识别
- `tts(text)`：语音合成
- `intent(text)`：意图解析
- `behavior(image)`：行为识别（P1）
- `fuse(inputs)`：多模态融合（P2）

## 7. 契约校验

契约校验测试位于 `cloud-server/tests/test_contract.py`，用 Python 标准库对样例负载做结构校验（必填字段、类型、枚举、优先级），不依赖额外第三方库。新增/修改契约时必须同步更新该测试。
